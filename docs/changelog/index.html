更新紀錄

桌面貓學會的新把戲，都記在這裡。

1.27.0

最新

2026年11月14日 · Claude 貓外掛 1.20.0

新功能

  • 安裝檔：桌面貓改用安裝檔，開始選單和桌面都會有捷徑。
  • 右鍵選單的「自動檢查更新」：每天看一次有沒有新版本，有的話先問你要不要更新。預設打開，不想要可以關掉。
  • 點伸手的貓：貓伸手等你回應時，點一下牠就會跳到那個對話（Claude 桌面版）。

從壓縮檔版換過來

  • 用 1.24.0 以前壓縮檔版的人，請 Claude 幫你安裝一次新的安裝檔，之後就會自動檢查更新。

1.24.0

2026年11月13日 · Claude 貓外掛 1.19.2

新功能

  • 英文介面：桌面貓和 Claude 貓都有英文了，會跟著 Windows 的語言自動選。
  • 右鍵選單的「語言」：可以自己換成 English 或繁體中文，兩隻貓一起換，馬上生效。
  • 右鍵選單的「請貓貓吃罐罐」：打開贊助頁。

小改動

  • 「隱藏貓咪／顯示貓咪」改成一個打勾的「顯示貓咪」。
  • 「外觀設定…」拿掉後面的「…」。
  • 罐罐的提示字一行放不下時，會在「・」那裡換行。

修正

  • 「永遠在最上層」的貓，不會再偶爾掉到別的視窗下面。
  • Claude 在下一步框問問題時，貓會伸手、喵一聲，不會跑去睡覺（Claude 桌面版）。
