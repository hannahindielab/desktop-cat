Changelog

Every new trick Desktop Cat has learned, all in one place.

1.27.0

Latest

November 14, 2026 · Claude Code plugin 1.20.0

New

  • Installer: Desktop Cat now comes as an installer, with shortcuts in the Start menu and on your desktop.
  • Automatically check for updates in the right-click menu: once a day the cat looks for a new version and asks you before it updates. It's on until you turn it off.
  • Click the waiting cat: when it's waiting for you, click it to jump to that conversation (in the Claude desktop app).

Coming from the zip version

  • If you use the zip version (1.24.0 or earlier), ask Claude to install the new installer once; from then on it checks for updates.

1.24.0

November 13, 2026 · Claude Code plugin 1.19.2

New

  • English: Desktop Cat and its Claude Code plugin now speak English, following your Windows language.
  • Language in the right-click menu: switch between English and 繁體中文 any time; both cats switch together, at once.
  • Buy the cat a can in the right-click menu: opens the tip page.

Changes

  • Show cat is now a checkbox.
  • The can hint wraps between its two parts when they don't fit on one line.

Fixes

  • Always on top stays on top: the cat no longer slips behind other windows now and then.
  • When Claude ends a turn with a question in the Claude desktop app's next-step box, the cat reaches out and meows once instead of going to sleep.
