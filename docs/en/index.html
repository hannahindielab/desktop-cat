FAQ

Is it free?

Yes. Desktop Cat and its Claude Code plugin are completely free, and the source code is on GitHub.

Does it send my data anywhere?

No. Desktop Cat only watches what Claude is doing on your own computer. It doesn't connect to the internet or send your data to anyone.

Do I need Claude?

Yes. The cat follows your Claude Code conversations, in the Code tab of the Claude desktop app or in a terminal.

Does it work on Mac?

For now, it's Windows only.
